# Kenya Country Pack

## Regulatory Framework

Metardu Access in Kenya operates under:

- **Survey Act Cap. 299** (Laws of Kenya) — primary surveying legislation
- **Survey Regulations 1994** — detailed procedural rules
- **RDM 1.1** (Registry of Documents Manual, 2025) — Survey of Kenya documentation standard
- **Sectional Properties Act 2020** — for sectional property surveys
- **Land Registration Act 2012** — for parcel registration

## Coordinate Reference System

- **CRS**: Arc 1960 / UTM zone 37S
- **EPSG**: 21037
- **Datum**: Arc 1960
- **Ellipsoid**: Clarke 1880 (RGS)
- **Projection**: Transverse Mercator
- **Zone**: 37S (central meridian 39°E)
- **Vertical datum**: Mean Sea Level (Mombasa tide gauge)

| Mutation | Parcel mutation | Desktop (Mutation Form generator) |

## Surveyor Identity

- **ISK**: Institution of Surveyors of Kenya
- **License format**: `ISK/1234`
- **Verification**: server-side via ArdhiSasa credentials
- **Sealing**: RSA-2048 cryptographic seal per Survey Regulations 3(2)

## Precision Requirements (Cadastral)

| Order | Precision Ratio | Use Case |
|-------|-----------------|----------|
| First | 1:25,000 | National control |
| Second | 1:10,000 | Secondary control |
| Third | 1:5,000 | Cadastral (minimum acceptable) |
| Fourth | 1:2,000 | Lower-order detail |

## Counties

Kenya has 47 counties. Full list in `manifest.json`. Major surveying activity centers:
- Nairobi (most cadastral work)
- Kiambu, Machakos, Kajiado (rapid development)
- Nakuru, Uasin Gishu (agricultural surveys)
- Mombasa, Kilifi, Kwale (coastal)

## GNSS RTK

- **Kenya CORS network**: VRS (Virtual Reference Station) via KENCORS
- **NTRIP mountpoints**: RTCM31, RTCM32
- **Subscription**: required via Survey of Kenya

## NLIMS / ArdhiSasa Integration

- **Submission format**: NLIMS-JSON-1.0
- **Submission endpoint**: `https://ardhiasasa.land.go.ke/api/v1/surveys`
- **Auth**: Client ID + secret (set in server-side environment)
- **Workflow**: mobile captures → sync → desktop generates statutory docs → web submits to NLIMS
